File Server and Web Server Setup Using Ubuntu Server on an Old PC


Duration:1y
Technologies Used: Ubuntu Server, Apache, Samba, Networking, Old PC hardware

Overview:

I successfully repurposed an old PC into a functional file server and web server using Ubuntu Server. This project involved setting up a secure and efficient server environment to host both files and web applications. The goal was to maximize the utility of older hardware while ensuring seamless performance for file sharing and web hosting.

Objectives:
	•	File Server: Set up Samba on Ubuntu Server to enable file sharing across multiple devices on a local network.
	•	Web Server: Configured Apache to host a website for testing and showcasing web applications.
	•	Networking: Utilized a router and network switch to establish a local network environment for file transfers and seamless communication between devices.

Key Steps and Implementation:
	1.	System Setup: Installed Ubuntu Server on the old PC and configured the necessary partitions and file systems.
	2.	File Server Configuration: Set up Samba to enable easy file sharing with Windows and Linux devices on the network.
	3.	Web Server Configuration: Installed and configured Apache to serve a basic static website and test web application.
	4.	Network Configuration: Ensured all devices were correctly connected using a network switch, optimizing the network speed and stability for file transfers and server access.
	5.	Security: Implemented basic security measures, including firewall setup and access control for both file and web services.

Outcomes:
	•	Successfully transformed the old PC into a reliable file and web server.
	•	Gained hands-on experience with server management, networking, and security.
	•	Enhanced my skills in system administration and network configuration.
